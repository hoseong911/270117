# 이미지 폴더

이 폴더에 사진을 넣고 커밋/푸시하면 청첩장(가로 버전)에 자동으로 반영됩니다.
파이어베이스 업로드 없이, 여기 파일 이름만 규칙에 맞추면 됩니다.

## 파일 이름 규칙

| 파일명 | 용도 |
|--------|------|
| `0.jpg` | 준비중(로딩) 화면 사진 — 세로 사진 권장 |
| `1.jpg` | 메인(표지) 화면 사진 — 세로 사진 권장 |
| `2.jpg` | 인트로(메인 다음) 화면 사진 — 세로 권장. 없으면 메인 사진으로 대체 |
| `w1.jpg`, `w2.jpg`, `w3.jpg` … | 갤러리 사진 |
| `001.jpg`, `002.jpg`, `003.jpg` … | 필름 사진 (인트로·인삿말 화면에 흐르는 옛날 사진) |

## 주의사항

- 확장자는 `.jpg` 로 통일해주세요.
- 번호는 `1`번부터 순서대로 붙여주세요. (중간에 10장 연속으로 비면 그 뒤는 안 읽습니다)
- 갤러리 사진은 `w` + 숫자(`w1`, `w2` …, 0 채우지 않음), 필름 사진은 세 자리(`001`)로 구분됩니다.
- 필름 사진은 자동으로 흑백 처리되며, 프레임에 맞게 잘려 들어갑니다(가로 3:2 비율이 가장 예쁨).
